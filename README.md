# Windows Event Log Analysis

## Project Overview

This project demonstrates how Windows Event Logs can be analyzed to detect suspicious activities using Event Viewer and Sysmon.

The objective is to understand attacker behavior by investigating Windows Security logs, PowerShell events, process creation events, and authentication logs.

---

## Objectives

- Analyze Windows Security Logs
- Identify suspicious login attempts
- Investigate PowerShell execution
- Detect malicious process creation
- Learn basic incident investigation
- Document findings
